# Onboarding for teammates

1. Accept the GitHub collaborator invite (check your email or https://github.com/notifications). You are added as an **admin**.
2. Clone the repo:
   ```bash
   git clone https://github.com/Humanberto/architectural-katas-2026.git
   cd architectural-katas-2026
   ```
3. Add your GitHub handle to the team table in `README.md` and open a pull request (see `CONTRIBUTING.md`).
4. Read the brief in `docs/kata-brief.pdf` and the evaluation criteria in `README.md`.
